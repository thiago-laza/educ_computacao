# Biblioteca de Artigos (CER/Educação em Computação)

Este repositório contém uma coleção de artigos científicos, focados na área de Educação em Computação (CER - Computing Education Research).

O objetivo deste projeto é organizar o acesso a esses materiais, disponibilizando tanto a versão original (em inglês) quanto a versão traduzida (em português brasileiro), facilitando o estudo e o acesso à literatura técnica.

## Objetivo do Projeto
- Facilitar a leitura e organização de artigos científicos.
- Oferecer uma interface simples e amigável para acesso aos arquivos.
- Apoiar o estudo de quem não domina completamente o inglês técnico.

## Como Contribuir
Este projeto está aberto para colaboração! Se você deseja ajudar, sinta-se à vontade para:
- **Tradução:** Contribuir com a tradução de novos artigos para o português.
- **Melhorias na página:** Propor melhorias na interface (`index.html`), organização, design ou funcionalidades.
- **Adição de conteúdo:** Sugerir e adicionar novos artigos relevantes à temática.

Para contribuir, abra um **Issue** ou envie um **Pull Request**.

## Estrutura do Projeto
- `index.html`: Página principal que lista os artigos.
- `Artigos_ordenados/`: Arquivos originais (Inglês).
- `Artigos traduzidos/`: Versões traduzidas (Português).
